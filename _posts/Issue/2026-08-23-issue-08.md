### 오픈라우터에 정체불명 모델이 하나 올라왔다

8월 20일, 오픈라우터(OpenRouter)에 `stealth/ox-alpha`라는 이름의 모델이 올라왔습니다. 만든 곳도, 공식 발표도 없이 모델 페이지 하나만 덜렁 생긴 상태였습니다. 그런데도 코딩과 장기 실행 에이전트 작업에서 반응이 좋다는 이야기가 퍼지면서 며칠 만에 개발자 커뮤니티의 화제가 됐고, Bloomberg까지 이 현상을 다뤘습니다.

오픈라우터가 "스텔스 모델"이라는 카테고리를 두는 이유는 간단합니다. 아직 공개하지 않은 모델을 실제 트래픽으로 테스트해보고 싶은 개발사가, 정체를 숨긴 채 무료로 풀어서 반응을 보는 방식입니다. GPT나 Gemini의 신모델도 정식 출시 전에 이런 식으로 먼저 등장한 적이 있습니다. Ox Alpha도 같은 패턴이지만, 이번엔 유독 정체를 알아내려는 시도가 많았습니다.

### 스펙부터 정리하면

| 항목 | 내용 |
|---|---|
| 등장일 | 2026년 8월 20일 |
| 컨텍스트 창 | 1,048,576 토큰 (약 100만) |
| 최대 출력 | 131,072 토큰 |
| 입력 | 텍스트, 이미지, 비디오 |
| 출력 | 텍스트 |
| 도구 호출 | 지원 (tools, tool_choice) |
| 가격 | 무료 (입력·출력 토큰 모두 과금 없음) |
| 응답 속도 | 초당 22토큰, 지연시간 6.09초 (P50 기준) |
| 가동률 | 99.99% (3일 평균) |

100만 토큰 컨텍스트는 대형 코드베이스를 통째로 넣고 질문할 수 있는 수준이고, 비디오 입력을 받는다는 점도 눈에 띕니다. 다만 오픈라우터 페이지에 안내된 대로 이 모델은 제3자 제공자가 직접 운영하며, 오픈라우터는 요청을 그대로 중계만 합니다. 프롬프트와 응답은 학습에 쓰지 않는다고 명시돼 있지만, 제공자 쪽에는 로그가 남습니다.

### 성능은 어느 정도인가

가장 많이 인용된 수치는 DeepSWE 벤치마크입니다. 초반에 10개 과제만 돌린 결과에서는 Ox Alpha가 80%를 기록해 화제가 됐지만, 이후 개발자 Ben Davis가 113개 전체 과제로 다시 돌린 결과는 63% Pass@1이었습니다.

같은 10개 과제 기준으로 비교하면 이렇습니다.

| 모델 | DeepSWE (10개 과제 기준) |
|---|---|
| Claude Fable 5 | 65% |
| Ox Alpha | 63% (113개 전체 과제 기준) |
| GLM-5.3 | 62% |
| Grok 4.6 | 62% |
| GPT-5.6 Sol | 52% |

즉 "GPT-5.6과 Claude를 능가한다"는 초기 주장은 소규모 샘플에서 나온 과장이었고, 전체 과제로 보면 GPT-5.6보다는 확실히 앞서지만 Claude Fable 5와는 비슷한 수준입니다.

### 정체는 Z.ai GLM-5.3일 가능성이 높다

공식 확인은 없지만, 커뮤니티가 여러 방식으로 지문을 대조했습니다.

- 지문 분석 도구 modelprint가 9가지 인프라 지표를 대조한 결과, Ox Alpha는 GLM-5.3과 6가지에서 일치했습니다.
- 토크나이저로 정규화한 토큰 수 4가지 지표가 모두 GLM 계열과 일치했습니다. Ben Davis가 25개 프롬프트로 직접 검증했을 때도 토큰 수가 거의 그대로 맞아떨어졌고, 차이 난 부분(+75토큰)은 숨겨진 래퍼(wrapper) 때문으로 추정됩니다.
- 비디오 입력 시 소모되는 토큰량이 4개 샘플 모두 GLM-5V-Turbo와 동일했습니다.
- GLM 특유의 오류 코드 "1301"이 그대로 나타났습니다.
- 1,000자당 이모지 사용 빈도(약 1.3개)나 지식 컷오프(2025년 11월 무렵)도 GLM 계열과 비슷합니다.

샤오미의 MiMo나 딥시크(DeepSeek)도 후보로 거론됐지만, 토크나이저와 비디오 토큰 지표가 맞지 않아 커뮤니티 조사에서는 대체로 배제됐습니다. Z.ai 쪽의 공식 인정이나 부인은 아직 나오지 않았습니다.

정식 정체가 밝혀지거나 서비스가 바뀌면 이 글도 업데이트하겠습니다.
