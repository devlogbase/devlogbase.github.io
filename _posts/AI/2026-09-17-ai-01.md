ChatGPT나 Claude를 매달 구독하기는 부담스럽지만, 필요할 때는 여러 최신 모델을 써 보고 싶은 경우가 있습니다. **PayPerQ AI**는 이런 상황을 겨냥해 채팅, 이미지, 영상, 음성 AI를 한곳에 모으고 사용량만큼 결제하는 서비스입니다. 다만 이 서비스의 핵심은 종량제만이 아닙니다. 모델마다 Anon, ZDR, TEE처럼 서로 다른 프라이버시 등급이 붙어 있어, 질문의 민감도에 맞춰 고를 수 있습니다.

### PayPerQ AI는 어떤 서비스인가요?

[PayPerQ](https://ppq.ai/)는 여러 생성형 AI 제공사의 모델을 하나의 웹 앱과 OpenAI 호환 API로 연결하는 서비스입니다. 계정을 만들지 않아도 사용할 수 있고, 구독 없이 잔액을 충전해 질의별로 비용을 내는 구조입니다. 공식 FAQ는 일반 웹 앱 사용자의 월평균 지출을 약 4달러로 안내하지만, 실제 지출은 모델과 대화 길이에 따라 크게 달라질 수 있습니다.

특정 모델 하나를 오래 쓰기보다, 간단한 질문에는 가벼운 모델을 고르고 코드 작성이나 긴 추론이 필요할 때만 고성능 모델을 고르는 사람에게 어울립니다. API도 OpenAI 형식을 지원하므로, 호환되는 도구에 기본 URL과 API 키를 넣어 연결할 수 있습니다.

### 종량제 비용은 어떻게 계산되나요?

PayPerQ의 비용은 단순히 메시지 한 번당 고정 금액으로 정해지지 않습니다. 선택한 모델의 입력 토큰과 출력 토큰 단가, 그리고 현재 대화에 포함되는 이전 메시지 길이가 함께 반영됩니다. 공식 가격표는 웹 앱의 평균 질의 비용을 1.5센트로 제시하지만, 이는 평균일 뿐입니다. 고성능 모델에 긴 문서를 넣거나 대화를 오래 이어 가면 비용은 빠르게 커질 수 있습니다.

처음에는 Auto Model 또는 저렴한 모델로 질문을 다듬고, 정말 중요한 한두 번의 요청에만 고성능 모델을 쓰는 방식이 관리하기 쉽습니다. 대화창에 오래 남은 맥락이 필요 없다면 새 대화를 열어 입력 토큰을 줄이는 방법도 있습니다. 모델별 입력과 출력 단가는 수시로 바뀔 수 있으므로, 결제 전에는 반드시 [PayPerQ 가격표](https://ppq.ai/pricing)를 확인하는 편이 정확합니다.

### Anon, ZDR, TEE 프라이버시 등급의 차이

PayPerQ를 익명 AI라고만 이해하면 중요한 차이를 놓치기 쉽습니다. 이 등급은 대화가 내 브라우저에 어떻게 저장되는지보다, 프롬프트가 모델 제공사로 전달된 뒤 읽히고 보관될 수 있는지를 설명합니다.

| 등급 | 제공사가 프롬프트를 읽을 수 있나요? | 보관 가능성 | 어울리는 상황 |
|---|---|---|---|
| Anon | 예 | 제공사 정책에 따라 가능 | 신원 연결을 줄이고 싶은 일상 질문 |
| ZDR | 요청 처리 중에는 가능 | 계약된 엔드포인트에서 보관하지 않음 | 업무 초안, 민감하지만 암호화까지는 필요하지 않은 내용 |
| TEE | 아니요 | 보관하지 않음 | 제3자가 평문을 읽지 못해야 하는 민감한 작업 |

Anon은 요청을 계정과 연결하지 않는 방식입니다. 하지만 프롬프트에 이름, 연락처, 비밀값을 직접 쓰면 그 내용 자체가 사라지는 것은 아닙니다. PayPerQ도 Anon 모델에서 제공사가 프롬프트를 보거나 보관할 수 있음을 안내합니다.

ZDR은 Zero Data Retention의 약자입니다. 프롬프트와 응답을 저장하거나 학습에 쓰지 않기로 한 제공사 엔드포인트로 요청을 보내는 방식입니다. 웹 앱에서는 ZDR 표기 모델이 해당 경로로 연결되지만, API에서는 요청마다 ZDR 옵션을 지정해야 합니다.

TEE는 Trusted Execution Environment를 뜻합니다. 기기에서 암호화한 요청을 하드웨어 기반 보안 영역에서만 복호화해 처리하는 방식으로, PayPerQ와 모델 제공사도 프롬프트 평문을 보지 못한다는 것이 공식 설명입니다. 가장 강한 보호 수준이지만, 지원 모델과 사용 방식이 제한될 수 있으므로 필요할 때 선택하는 편이 좋습니다.

### PayPerQ AI가 잘 맞는 사람

- 한두 개 모델의 월 구독료가 아까워 가끔만 고성능 AI를 쓰는 사람
- Gemini, GPT, Claude 계열처럼 여러 모델의 결과를 같은 화면에서 비교하려는 사람
- 모델 제공사에 계정 정보가 함께 전달되는 것을 피하고 싶은 사람
- OpenAI 호환 API로 여러 모델을 실험하려는 개발자

반대로 매일 같은 고성능 모델을 장시간 사용한다면 월 구독 상품이나 해당 모델의 공식 API와 월간 비용을 비교해야 합니다. PayPerQ의 장점은 언제나 최저가라는 뜻이 아니라, 모델을 바꿀 수 있고 쓰지 않는 달에는 고정비가 없다는 데 있습니다. 모델별 단가를 확인하는 관점은 [Gemini API 가격이 바뀌는 시점과 비용 계산](/ai/20260814-01/)에도 함께 정리해 두었습니다.

### 사용 전에 확인할 점

대화 기록을 브라우저에 기본 저장한다는 설명과, 추론 요청이 모델 제공사로 전송되는 일은 별개의 문제입니다. 일반 모델에서는 요청이 서비스와 제공사를 거쳐 처리되므로, 계약서 원문, 인증 정보, 개인식별번호처럼 유출 피해가 큰 정보는 Anon 모델이라도 입력하지 않는 편이 안전합니다.

특히 ZDR은 대화 내용이 영원히 사라진다는 일반적인 보안 약속이 아니라, 선택한 엔드포인트의 보관 정책에 관한 설명입니다. TEE도 모델 목록과 구현 방식이 바뀔 수 있으므로, 민감한 업무에 쓰기 전에는 [공식 개인정보 등급 설명](https://ppq.ai/blog/anon-vs-zdr-vs-tee-privacy-tiers)과 현재 모델 표기를 다시 확인해야 합니다.

### 자주 묻는 질문

**PayPerQ는 회원가입 없이 쓸 수 있나요?**

가능합니다. PayPerQ는 계정 생성이 선택 사항이며, 잔액을 충전해 바로 사용하는 방식을 안내합니다. 여러 기기에서 대화 기록을 동기화하려면 별도의 계정과 암호화된 동기화 기능을 확인해야 합니다.

**Anon 모델에 개인정보를 넣어도 되나요?**

권하지 않습니다. Anon은 요청과 계정의 연결을 줄이는 등급이며, 프롬프트에 직접 입력한 개인정보를 자동으로 지우지 않습니다. 제공사가 프롬프트를 읽거나 보관할 가능성도 있습니다.

**ZDR과 TEE 중 무엇을 골라야 하나요?**

보관과 학습이 걱정되는 민감한 업무 내용이라면 ZDR을 먼저 검토할 수 있습니다. 서비스 운영자와 모델 제공사 모두가 평문을 읽을 수 없기를 원한다면 지원되는 TEE 모델이 더 높은 보호 수준입니다.

**긴 대화가 왜 더 비싸질 수 있나요?**

모델이 이전 대화 내용을 함께 읽어야 한다면 그 내용도 입력 토큰으로 계산되기 때문입니다. 필요한 맥락이 끝났다면 새 대화를 시작하는 것이 비용을 예측하기 쉽습니다.

PayPerQ AI는 단순히 저렴한 AI 구독 대체재라기보다, 모델과 개인정보 처리 수준을 요청별로 선택하는 도구에 가깝습니다. 먼저 할 일은 가장 좋은 모델을 찾는 것이 아니라, 질문에 담긴 정보가 어느 수준의 보호를 필요로 하는지 판단하는 일입니다.
