OpenAI가 9월 29일 GPT-6.1 Sol을 내놨습니다. API 가격은 입력 100만 토큰당 2달러, 출력 10달러로 일주일 전에 나온 GPT-6 Sol과 똑같습니다.

달라진 건 캐시 입력 단가입니다. 0.20달러에서 0.10달러로 반토막이 났고, 그 밖의 단가는 그대로인데 성능은 올랐다는 게 OpenAI의 설명입니다. 그러면 지난 7월에 20% 인하된 GPT-5.6 Terra와는 얼마나 차이가 날까요.

세 모델의 API 가격을 항목별로 나란히 놓고, 같은 작업을 돌렸을 때 실제로 얼마가 나오는지까지 계산했습니다.

입력 단가는 셋 다 같고 차이는 두 군데서 납니다. 출력은 Terra가 Sol보다 20% 비싸고, 캐시 입력은 6.1 Sol만 절반입니다.

Terra가 원래 저렴한 라인이라는 인식이 있어서 이 결과가 의외였습니다. OpenAI가 7월 30일에 Terra를 20% 내리기 전에는 입력 2.50달러, 출력 15달러였고, 그 인하 후 가격이 지금의 2달러와 12달러입니다. 그런데 새로 나온 Sol은 입력이 같고 출력이 더 쌉니다.

## GPT-6.1 Sol이란 무엇인가

GPT-6.1 Sol은 GPT-6 Sol의 업그레이드 버전입니다. OpenAI는 코딩, 컴퓨터 사용, 전문 업무에서 최상위 모델인 GPT-6 Astra에 근접한 성능을 Astra 표준 가격의 5분의 1에 낸다고 설명합니다.

Astra의 표준 가격은 입력 10달러, 출력 50달러, 캐시 입력 1달러입니다. 6.1 Sol은 여기서 딱 5분의 1이 됩니다. OpenAI가 발표문에 함께 실은 모델 카드에는 GPT-6 Luna의 가격(입력 0.10달러, 출력 0.50달러, 캐시 입력 0.01달러)도 나와 있습니다.

OpenAI가 공개한 수치 중 가격과 직접 관련된 것은 이렇습니다.

- 코딩 평가 DeepSWE v1.1에서 Astra와 같은 점수를 내면서 비용은 약 5분의 1입니다
- 같은 평가에서 GPT-6 Sol의 최고 점수를 6.4점 앞서면서 추론 강도는 더 낮고 비용도 낮습니다
- 컴퓨터 사용 평가 OSWorld 2.0의 최대 추론 설정에서 GPT-6 Sol보다 7점 높고, 작업당 비용은 절반 이하입니다
- 과학 작업 평가 Terminal-Bench Science 0.1의 최대 추론 설정에서 작업당 평균 5.47달러가 들었고, Opus 5.5는 23.21달러, Astra는 23.80달러입니다

이 수치는 모두 OpenAI가 고른 평가와 설정에서 나온 값입니다. 다만 토큰 단가가 같아도 작업당 비용이 줄었다는 건, 같은 일을 더 적은 토큰으로 끝낸다는 뜻입니다. 단가표만 봐서는 이 차이가 보이지 않습니다.

## 같은 작업을 돌리면 얼마가 나올까

단가표만으로는 감이 안 와서 두 가지 경우를 계산해 봤습니다. 모델이 쓰는 토큰 수는 같다고 가정한 계산입니다.

**경우 1. 캐시 없이 입력 100만 토큰, 출력 20만 토큰**

- GPT-5.6 Terra : 2.00 + 2.40 = 4.40달러
- GPT-6 Sol : 2.00 + 2.00 = 4.00달러
- GPT-6.1 Sol : 2.00 + 2.00 = 4.00달러

**경우 2. 에이전트처럼 입력 100만 토큰 중 90만 토큰이 캐시, 출력 20만 토큰**

- GPT-5.6 Terra : 0.18 + 0.20 + 2.40 = 2.78달러
- GPT-6 Sol : 0.18 + 0.20 + 2.00 = 2.38달러
- GPT-6.1 Sol : 0.09 + 0.20 + 2.00 = 2.29달러

경우 1에서는 6.1 Sol이 Terra보다 9% 쌉니다. 경우 2에서는 17.6% 쌉니다. 캐시 비중이 클수록, 출력이 많을수록 격차가 벌어집니다.

반대로 GPT-6 Sol과 6.1 Sol의 차이는 경우 2에서도 0.09달러로 4% 남짓입니다. 캐시 입력 절감은 컨텍스트를 반복해서 재사용하는 코딩 에이전트나 긴 문서 질의응답에서만 체감이 큽니다.

## 가격표에 안 보이는 조건들

6.1 Sol의 세부 요금은 OpenAI 발표문에 다 나와 있지 않아서 [DataCamp의 정리](https://www.datacamp.com/blog/gpt-6-1-sol)를 참고했습니다. 실제 결제 전에는 OpenAI 가격 페이지로 다시 확인하는 편이 좋을 것 같습니다.

- **긴 프롬프트 할증** : 프롬프트가 27만 2천 토큰을 넘으면 그 요청 전체에 입력과 캐시 요금 2배, 출력 1.5배가 붙습니다. 컨텍스트 창은 105만 토큰이지만 요금이 싼 구간은 27만 2천 토큰까지입니다.
- **Fast 모드** : 표준 요금의 2배입니다.
- **Batch와 Flex** : 표준 요금보다 50% 저렴합니다.
- **지역 처리** : 지원되는 지역에서는 10% 할증이 붙습니다.
- **Ultrafast 옵션** : Codex에서 나올 예정으로 알려졌지만, 발표 시점에 가격은 확정되지 않았습니다.

GPT-6 Sol과 GPT-5.6 Terra에 같은 할증 구조가 적용되는지는 확인하지 못했습니다. 긴 프롬프트를 쓰는 작업이라면 이 부분을 각 모델 문서에서 따로 봐야 합니다.

## 그럼 어떤 모델을 골라야 할까

가격만 놓고 보면 결론은 단순합니다. GPT-5.6 Terra를 쓰던 API 작업이라면 6.1 Sol로 바꿔도 입력 비용은 같고 출력 비용은 줄어듭니다.

다만 Terra는 5.6 세대의 균형형 라인이고, 6.1 Sol은 6세대 Sol 계열이라 두 모델을 직접 비교한 공식 평가는 찾지 못했습니다. 지금 Terra로 품질에 불만이 없다면 굳이 옮길 이유는 가격 차이 정도입니다.

GPT-6 Sol을 쓰고 있다면 옮기지 않을 이유가 거의 없습니다. 기본 단가는 같고 캐시 입력은 절반이며, 발표문 기준으로 대부분의 평가에서 성능이 올랐습니다.

가장 어려운 과학 연구 작업은 여전히 Astra가 맞습니다. OpenAI도 Terminal-Bench Science에서 Astra가 가장 높은 점수(68.1%)를 냈고 이런 작업에는 Astra를 써야 한다고 밝혔습니다.

## 자주 묻는 질문

**GPT-6.1 Sol API 가격은 얼마인가요?**

입력 100만 토큰당 2달러, 캐시된 입력 0.10달러, 출력 10달러입니다. 컨텍스트 창은 105만 토큰이고 프롬프트가 27만 2천 토큰을 넘으면 할증이 붙습니다.

**GPT-6 Sol과 GPT-6.1 Sol의 가격 차이는 얼마인가요?**

입력과 출력 단가는 같습니다. 캐시된 입력만 0.20달러에서 0.10달러로 내려갔습니다.

**GPT-5.6 Terra는 지금도 6.1 Sol보다 싼가요?**

아닙니다. 입력은 2달러로 같고 출력은 Terra가 12달러, 6.1 Sol이 10달러입니다. 캐시 입력도 Terra는 0.20달러입니다.

**GPT-5.6 Sol과는 얼마나 차이가 나나요?**

GPT-5.6 Sol의 표준 요금은 입력 5달러, 출력 30달러입니다. 다만 OpenAI가 8월 21일부터 3개월간 20% 넘게 내린다고 밝혔기 때문에 지금 실제 청구 단가는 이보다 낮습니다.
