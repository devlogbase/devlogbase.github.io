구글이 9월 30일 새 최상위 모델 제미나이 4 아르곤(Gemini 4 Argon)을 공개했습니다. 구글이 낸 비교표의 벤치마크 19개 가운데 13개에서 단독 1위이고 API 출시 가격은 입력 100만 토큰당 2달러, 출력 10달러로 클로드 오퍼스 5.5의 절반입니다.

그런데 지금 이 모델을 쓸 수 있는 곳은 구글이 선별한 사이버 방어 기관뿐입니다. 일반 개발자와 구독자에게 열리는 날짜는 나오지 않았고 2달러와 10달러라는 가격도 기간이 정해지지 않은 출시 가격입니다. 발표문에서 확인되는 내용과 아직 비어 있는 내용을 나눠 정리했습니다.

## 제미나이 4 아르곤이란 무엇인가

제미나이 4 아르곤은 구글 딥마인드가 소프트웨어 엔지니어링, 법률과 금융 같은 기업 지식 업무, 사이버 보안 방어를 겨냥해 내놓은 최상위 모델입니다. 길고 여러 단계로 이어지는 작업에서 추론을 유지하는 데 초점을 맞췄다고 구글은 설명합니다.

눈에 띄는 사양 변화는 출력 토큰 한도입니다. 이전 6만 4,000 토큰에서 100만 토큰으로 늘었습니다. 한 번의 실행에서 수십만 토큰을 생각하고 생성할 여유를 주기 위해서라는 설명입니다.

구글은 사내에서 이미 쓰고 있는 사례도 공개했습니다.

- 데이터센터 메모리 최적화 : 아르곤 에이전트가 프로파일링 데이터를 분석해 최적화를 적용했고 배포가 끝나면 300 TiB 이상의 메모리가 확보됩니다.
- C/C++ 코드의 Rust 이전 : re2, libgav1 같은 수만 줄 규모 라이브러리부터 80만 줄이 넘는 Fuchsia Zircon 커널까지 작업 중입니다.
- 영상 디코더 libgav1 : 기존 Rust 포팅본의 SIMD 코드 3만 2,000줄을 교체해 2.7배 빨라졌습니다.

모두 구글이 직접 밝힌 수치이고 외부에서 검증된 결과는 아닙니다.

## 제미나이 4 아르곤이 뒤지는 5개 항목과 1위 모델

구글도 모든 항목에서 이겼다고 주장하지 않습니다. 표에서 아르곤이 진 항목은 아래 5개입니다.

| 벤치마크 | 아르곤 | 1위 모델 | 1위 점수 |
| --- | --- | --- | --- |
| FrontierSWE v2 | 55.0% | GPT-6 아스트라 | 65.5% |
| Terminal-Bench Science 0.1 | 57.6% | GPT-6 아스트라 | 68.1% |
| Terminal-bench 4.0 | 57.4% | 오퍼스 5.5 | 66.4% |
| PostTrainBench | 45.3% | 오퍼스 5.5 | 49.3% |
| OSWorld-2.0 | 69.2% | GPT-6 아스트라 | 72.6% |

FrontierSWE v2와 Terminal-Bench Science 0.1에서는 아스트라와 10.5%포인트씩 차이가 납니다. 터미널에서 일하는 코딩 에이전트 용도라면 아르곤이 가장 좋은 선택이라고 말하기 어려운 숫자입니다.

Terminal-bench 4.0은 이 블로그의 [클로드 소넷 5.5 글](/ai/20260929-01/)에서도 다룬 평가입니다. Anthropic 발표 기준으로 소넷 5.5가 70.6%였는데 구글 표에는 소넷 5.5가 들어 있지 않습니다. 비교 대상 모델은 발표한 구글이 골랐습니다.

사이버 보안 평가 CWE-bench v1에서는 아르곤과 아스트라가 68.0%로 같습니다.

## 제미나이 4 아르곤 가격은 입력 2달러와 출력 10달러, 다만 출시 가격입니다

구글 발표문이 밝힌 출시 가격은 입력 100만 토큰당 2달러, 출력 10달러입니다. 캐시된 입력은 입력 가격에서 95% 할인되므로 0.10달러입니다.

벤처비트 보도에 따르면 출시 가격 기간이 끝나면 입력 4달러, 출력 20달러로 오릅니다. 이 가격은 오퍼스 5.5와 같습니다. 출시 가격이 언제까지 적용되는지는 구글이 밝히지 않았습니다.

| 모델 | 입력 | 출력 |
| --- | --- | --- |
| 제미나이 4 아르곤 (출시 가격) | 2달러 | 10달러 |
| 제미나이 4 아르곤 (출시 가격 종료 후) | 4달러 | 20달러 |
| 클로드 오퍼스 5.5 | 4달러 | 20달러 |
| GPT-6 아스트라 | 10달러 | 50달러 |
| 클로드 소넷 5.5 | 2달러 | 10달러 |
| GPT-6.1 Sol | 2달러 | 10달러 |

출시 가격만 보면 최상위 모델을 중간 등급 모델인 소넷 5.5, GPT-6.1 Sol과 같은 값에 쓰는 셈입니다. 출시 가격 기간이 끝나면 오퍼스 5.5와 같은 값을 내게 됩니다. 소넷 5.5와 GPT-6.1 Sol 가격은 각 사의 출시 발표 기준이고 [클로드 소넷 5.5 글](/ai/20260929-01/)과 [GPT-6.1 Sol 가격 비교 글](/ai/20260930-01/)에 정리해 두었습니다.

## 제미나이 4 아르곤은 지금 쓸 수 없습니다, 공개 순서는 이렇습니다

아르곤은 현재 구글의 Fairwind Program에 속한 신뢰할 수 있는 사이버 방어 기관에만 제공됩니다. 구글은 이 수준의 모델을 안전하게 내놓으려면 단계적으로 접근해야 한다고 설명했고 미국 정부의 출시 전 모델 접근 절차에도 참여하고 있다고 밝혔습니다.

발표문에서 확인되는 공개 순서는 다음과 같습니다.

1. Fairwind Program의 사이버 방어 기관과 신뢰 테스터 (현재)
2. 유료 API 고객과 Google AI Ultra 구독자
3. 그 밖의 개발자, 기업, 일반 사용자

2단계와 3단계의 날짜는 없습니다. 구글은 가능한 한 빨리라고만 적었습니다.

넓게 공개하기 전에 보강하겠다고 밝힌 안전장치는 네 가지입니다. 사이버 공격과 화학, 생물, 방사능, 핵 분야 악용 방지, 간접 프롬프트 주입 방어, 모델이 사용자 의도를 벗어나 행동하는지 감시하는 장치, 고위험 평가를 돌리는 샌드박스 환경 강화입니다.

사이버 방어 기관과 구글 내부 팀에는 사이버 보안 제한을 뺀 버전을 제공한다는 점도 발표문에 들어 있습니다. 보안 기업 Wiz는 이 모델로 전 세계 병원이 쓰는 의료 소프트웨어에서 개인정보가 노출되는 치명적 취약점을 찾았다고 구글은 전했습니다.

## 자주 묻는 질문

**제미나이 4 아르곤은 언제부터 쓸 수 있나요?**

날짜는 공개되지 않았습니다. 지금은 선별된 사이버 방어 기관만 쓸 수 있고 다음 순서는 유료 API 고객과 Google AI Ultra 구독자입니다.

**제미나이 4 아르곤 API 가격은 얼마인가요?**

출시 가격은 입력 100만 토큰당 2달러, 출력 10달러입니다. 벤처비트는 출시 가격 기간이 끝나면 4달러와 20달러가 된다고 보도했습니다.

**제미나이 4 아르곤은 GPT-6 아스트라보다 성능이 좋은가요?**

구글이 공개한 19개 항목 중 13개에서 아르곤이 단독 1위입니다. FrontierSWE v2, Terminal-Bench Science 0.1, OSWorld-2.0에서는 아스트라가 앞섭니다.

**제미나이 앱 무료 사용자도 아르곤을 쓸 수 있나요?**

발표문에는 유료 API 고객과 Google AI Ultra 구독자부터 제공한다는 내용만 있습니다. 무료 사용자 제공 여부와 시기는 나오지 않았습니다.
